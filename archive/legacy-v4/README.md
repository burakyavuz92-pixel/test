# Eski pleyt sözleşmesi arşivi

Bu C# dosyaları aktif src projesine dahil değildir. v1–v4 model tarifleri ve 82 pleyt üreten adaptör geri izleme amacıyla saklanır. Mevcut CLI v5 genel işlem tarifi kullanır; bu dosyalara geri dönüş veya eski kayıtları çizme komutu içermez. Tarihsel OCCT pleyt deneyi experiments/occt altında kalır, yeni tarif akışı onu çağırmaz. Arşiv bir genel CAD yürütücüsü değildir.
