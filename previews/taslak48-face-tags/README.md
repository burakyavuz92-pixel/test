# STEP yüz adı — yerel altyapı testi

Bu dosyalar yeni API yorumunun sonucu değildir. Taslak4.7 için önceden doğrulanan altı geometri kullanılmış; 4.8 JPEG'inde işaretli iç taban düzlemi yerel olarak z=-3 mm seçilip montaj adıyla kaydedilmiştir. 4.8 için API çağrısı otomatik onay incelemesi tarafından engellendi; model eşleştirmesi henüz test edilmedi.

XDE/STEPCAF ile alt yüz adı yazılıp geri okundu. Her adın gerçek yüz olarak bulunması, alanı, ağırlık merkezi ve katı hacmi doğrulandı. İsim geometriyi kazımaz; ADVANCED_FACE adıdır. JPEG'e ölçü/etiket eklenmez.
