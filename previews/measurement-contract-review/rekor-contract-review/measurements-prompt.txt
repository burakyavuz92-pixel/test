Read the JPEG, nominal Excel table and supplied CadQuery geometry. Produce measurement references for that geometry without changing it. Use the same build_measurements(p) function for every row. p contains nominal millimetres; local software supplies visible values, replacement text, symbols, tolerances, arrows and layout, and does not draw zero-valued dimensions.

Coordinate reference: in the section view on the left of the source JPEG, the direction toward page-left is +Z. The centre of the end face on that side is the origin; the body extends towards -Z. In the main view, +X is page-right and +Y is page-up. This page-left rule refers to the source section, not the isometric view. All geometric points, centres and directions below use the generated solid's world XYZ coordinates, after any CadQuery workplane transformations.

Return only JSON with this structure:

Visual markers:
- Report bracketed measurement occurrences only. Identical text at different locations has independent unique ids. @ surface labels belong to STEP, not measurements. OCR determines which bracketed occurrences may be drawn.
- Image coordinates are 0..1 in the full JPEG, with origin top-left and y downward. view is front or section, selected from arrow targets and geometry.
- Each marker contains the fields shown above; omit sectionAxisNormalized for front. For section, the stated page-left +Z direction is [-1,0]. Repeat the same actual geometry bounding box for every marker in a view; exclude labels and dimension lines.
- A leader has one arrow tip; a linear measurement has two. Marker centre, frame and arrow positions must be known. If an occurrence cannot be located, omit its marker and return its measurement as unresolved rather than putting null in coordinate fields.

build_measurements(p) returns a list of records. Each resolved record has id, markerId matching its marker, source preserving the bracket content (including literal tolerances/chamfer text), kind and nominal. ids are unique per occurrence; source is the Excel column or literal content, not the occurrence id. Follow the indicated feature even when another feature has the same value. Written nominal dimensions take priority over schematic pixel proportions.

Resolved reference fields by kind (directions/axes are unit vectors):
- diameter: center on the axis, axis, radius. Support may be a cylinder or full circular edge, including a cone end circle.
- radius: center of the indicated circular arc, axis normal to its plane, radius, and point on that actual arc.
- distance or thickness: points:[[x1,y1,z1],[x2,y2,z2]], direction. Choose both endpoints on actual surfaces or edges of the finished solid at the two measured positions. Their radial positions may differ: nominal is the absolute separation projected onto direction, not necessarily their diagonal distance. For a distance explicitly between parallel cylindrical axes, points may instead lie on those actual axes and direction is perpendicular to them.
- chamfer: points at the boundaries of the same indicated chamfer face, direction along the dimensioned leg, nominal equal to that leg, angleDeg. Use kind chamfer, including for a single-arrow leader. Excel provides p[label] for the leg and p[label+"__angleDeg"] for its angle.

If the entire row cannot yield measurement data, return {"error":"short Turkish reason for this row"}. Successful rows return data only.

import math
import cadquery as cq

COLLAR_TOTAL_MM = 5.0
LAND_MM = 1.0


def _val(p, key):
    v = p.get(key)
    if v is None:
        return None
    return float(v)


def _dims(p):
    out = {}
    for k in ['A', 'B', 'C', 'D', 'E', 'J', 'K', 'L', 'M', 'N']:
        v = _val(p, k)
        if v is None:
            return None
        out[k] = v
    return out


def _leg(p, key):
    leg = _val(p, key)
    if leg is None:
        return None, None
    if leg == 0.0:
        return 0.0, 0.0
    ang = p.get(key + '__angleDeg')
    if ang is None:
        return None, None
    return leg, leg * math.tan(math.radians(float(ang)))


def _profile(p):
    v = _dims(p)
    if v is None:
        return None, 'eksik ölçü'
    fl, fr = _leg(p, 'F')
    gl, gr = _leg(p, 'G')
    jl, jr = _leg(p, 'J')
    if fl is None or gl is None or jl is None:
        return None, 'açı verisi eksik'
    RA = v['A'] / 2.0
    RB = v['B'] / 2.0
    RK = v['K'] / 2.0
    RE = v['E'] / 2.0
    RL = v['L'] / 2.0
    RN = v['N'] / 2.0
    C = v['C']
    D = v['D']
    M = v['M']
    if C <= 0 or M <= 0 or D < 0:
        return None, 'ölçü değerleri geçersiz'
    if D > 0 and fl >= D:
        return None, 'kademe derinliği yetersiz'
    bore_left = RB if D > 0 else RK
    if RA - jr <= bore_left + fr:
        return None, 'duvar kalınlığı yetersiz'
    if RN <= RK + gr or RL <= RN:
        return None, 'kollar çapı geçersiz'
    zC = -C
    zM = -(C + M)
    zL = zM - LAND_MM
    zE = -(C + M + COLLAR_TOTAL_MM)
    pts = []
    pts.append((bore_left + fr, 0.0))
    pts.append((bore_left, -fl))
    if D > 0:
        pts.append((RB, -D))
        pts.append((RK, -D))
    if gl > 0:
        pts.append((RK, zE + gl))
        pts.append((RK + gr, zE))
    else:
        pts.append((RK, zE))
    pts.append((RN, zE))
    pts.append((RL, zL))
    pts.append((RL, zM))
    pts.append((RE, zM))
    pts.append((RE, zC))
    pts.append((RA, zC))
    pts.append((RA, -jl))
    pts.append((RA - jr, 0.0))
    return pts, None


def _build(p):
    pts, err = _profile(p)
    if err is not None:
        return None, err
    try:
        wp = cq.Workplane('XZ').polyline(pts).close().revolve(360, (0, 0, 0), (0, 1, 0))
        solid = wp.val()
        if (not solid.isValid()) or solid.Volume() <= 0:
            return None, 'geometri geçersiz'
    except Exception:
        return None, 'geometri oluşturulamadı'
    return wp, None


def build_part(p):
    wp, err = _build(p)
    if err is not None:
        return {'error': err}
    return wp


def build_face_tags(p):
    v = _dims(p)
    if v is None:
        return {'error': 'eksik ölçü'}
    z_shoulder = -(v['C'] + v['M'])
    return [{'name': 'montaj', 'surface': {'kind': 'plane', 'normal': [0.0, 0.0, 1.0], 'offset': z_shoulder}}]
