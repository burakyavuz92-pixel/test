## İndirme ve alternatif biçim

[taslak47-step-files.zip](taslak47-step-files.zip) içinde AP214 (.step) ve AP203 (.stp) sürümleri bulunur. ZIP dosyasını Download raw file ile indirip açın. AP203 sürümleri tekrar okunarak BRep ve hacim korunumu doğrulandı; SolidWorks üzerinde test edilmedi.

GitHub HTML sayfasını farklı kaydetmek STEP dosyasını indirmez. Gerçek STEP metni ISO-10303-21; ile başlar. Bir dosya açılmazsa indirilen kopyanın boyut ve SHA256 değeri ap203-verification.json ile karşılaştırılabilir.
