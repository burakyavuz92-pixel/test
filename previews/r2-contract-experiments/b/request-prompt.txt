VALUES
N is a finite number or an expression string starting with =, such as "=A", "=A/2-3". Column identifiers resolve to nominalMm from tableInput; blank resolves to null, zero to 0. Optional geometry.variables maps names to expressions, e.g. {"R":"=A/2"}. Variables can refer to other variables; software evaluates them on demand per row and rejects cycles. Names are unique identifiers and cannot shadow column names.
Expressions support decimal literals, column/variable names, parentheses, + - * /, comparisons == != < <= > >=, and/or/not, true/false/null, isblank(x), if(test,a,b), sqrt(x), abs(x), min(a,b), max(a,b), sin(x), cos(x). Trigonometric arguments are degrees. Usual arithmetic precedence applies, then comparisons, then not/and/or; parentheses make grouping explicit. if/and/or evaluate only the needed branches. Blank arithmetic is an error. Expressions contain no executable code, loops or assignments.
P2=[N,N] in the profile frame; P3=[N,N,N] in world coordinates unless explicitly specified otherwise. Model lengths are mm, angles degrees, counts integers; direction vectors are dimensionless. Numeric constants take their field's units.
Frame={origin:P3,u:P3,v:P3}; u/v are perpendicular nonzero directions, normalized locally; normal=u cross v. An omitted frame means origin [0,0,0], u=[1,0,0], v=[0,1,0]. The round part's top-face center is [0,0,0]; +X is page-right, +Y page-up, +Z outward from that face. The body extends towards -Z.

GEOMETRY
features is a construction sequence acting on ONE current body. Each feature has {id,op,when?}; when is a boolean or expression, default true. False skips the whole feature before its shape/selector expressions are evaluated. The first active feature is add. Each following feature updates the current body; the last current body is the result. IDs identify operations for dimension and edge references.

add/cut: {id,op:"add"|"cut",shape:Shape,instances?,when?}. Software builds the shape and unions/subtracts it. A cut must remove material. Intermediate bodies may contain multiple solids; the finished part is one solid.
fillet/chamfer: {id,op:"fillet"|"chamfer",size:N,selectors:[EdgeSelector,...],when?}. Select edges of the current body. Chamfer is equal-distance.

Shape choices:
- {kind:"cylinder",origin:P3,direction:P3,diameter:N,length:N}. Positive diameter/length, starts at origin.
- {kind:"box",frame?:Frame,size:[N,N,N]}. Frame origin is the corner; sizes along u,v,normal.
- {kind:"extrude",profile:Profile,extent:{from:N,to:N}|"throughAll"}. Distances from/to are signed offsets along u cross v from the profile frame origin; from < to. throughAll is for cuts: software spans the current body's bounds with a local allowance.
- {kind:"revolve",profile:Profile,axisOrigin:P3,axisDirection:P3,angleDeg:N}. Right-hand rotation, 0<angleDeg<=360; axis is in the profile plane. Profile may touch, but not cross, the axis.
Profile={frame?:Frame,outer:Loop,holes?:[Loop,...]}. Loop choices:
- {kind:"circle",center:P2,diameter:N}
- {kind:"polyline",points:[P2,...]}
- {kind:"roundedSlot",center:P2,width:N,length:N,angleDeg:N}; overall tip-to-tip length, angle from local +u.
- {kind:"path",start:P2,segments:[Segment,...]}. Segment={kind:"line",end:P2} or {kind:"arc",mid:P2,end:P2}. Each segment starts at the previous endpoint; the first starts at path.start. An arc passes through its start, mid and end. The final end equals path.start; every boundary edge is supplied, with no implicit closing edge.
Polyline vertices are ordered; software adds the final straight edge back to the first vertex. Do not repeat the first vertex. Path and polyline have no closed field. These rules apply to outer loops and holes.

instances applies copies of the shape before its add/cut:
{kind:"linear",count:N,step:P3} includes i=0 through count-1, translation i*step.
{kind:"polar",count:N,axisOrigin:P3,axisDirection:P3,startAngleDeg:N,stepAngleDeg:N} rotates the supplied shape around the world-space axis by start+i*step. The supplied shape already occupies its seed location, including its radial offset. Each instance's orientation rotates with it. A count of n produces exactly n copies, indexed 0 to n-1, not n additional copies. Without instances there is one copy. instance references are zero-based. The copies are combined before the body update.

EdgeSelector={faces:[Surface,Surface]}. Select the shared boundary edge of the two incident support surfaces on the current body, before this fillet/chamfer. Surface choices:
- {kind:"plane",normal:P3,offset:N}: dot(unit(normal),worldPoint)=offset.
- {kind:"cylinder",axisOrigin:P3,axisDirection:P3,radius:N}: cylindrical support surface around that world-space axis.
The pair identifies exactly one shared edge; no approximate edge point is required. Fillet size is the radius in mm; chamfer size is the equal distance along each incident face. For other surface types use EdgeSelector={pointOnEdge:P3,directionKind:"axis"|"tangent",direction:P3}, with an actual point on the edge in world coordinates. axis is the circular edge axis; tangent is the edge tangent there.

DRAWING
Geometry uses nominal values. Dimension values/tolerances come from valueSource independently of construction expressions.

dimensions: {id,type,valueSource,targets:[{operation:id,role:string,instance?:integer}],axis,when?,quantity?}.
type=diameter|pitchDiameter|distance|angle|radius|thickness; axis=X|Y|Z|radial. valueSource={kind:"column",column:string} retains that cell's original tolerance, or {kind:"constant",value:number,unit:"mm"|"deg"}. role describes the measured entity/relation. Defaults: when=true, quantity=1. A dimension's condition can follow the optional feature it refers to.

geometricTolerances: {kind,value:N,targets:[{operation:id,role:string,instance?:integer}]}.

For this investigation, each fillet also carries sourceMark={label:string,arrowTip:[number,number]|null,location:string}. arrowTip locates the annotation arrowhead, not its text, in original JPEG coordinates normalized from 0 to 1 (left to right, top to bottom). location names the physical boundary shown there in at most 15 words. Derived, unannotated radii use arrowTip:null. This is audit metadata, not a construction parameter.
