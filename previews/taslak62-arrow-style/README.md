# Ok ve çap gösterimi revizyonu

Ok uçları 8→10, yarı genişlik 2→3 çizim birimine büyütüldü. Dairesel ölçülerde uygun yer varsa çemberi geçen eğik çizgi ve çizgiye paralel yazı kullanılır; konum çakışırsa mevcut lider alternatifleri denenir. 25 için özel ölçü-değeri kuralı yoktur.

Kayıtlı geometri ve referanslarla tekrar çizildi; yeni API çağrısı yok. Önceki referans sınırlamaları, 733001-03 satırındaki eksikler ve sol pahın model tarafından seçilen tarafının kaynak oka uygunluğu konusu devam eder. STEP geometrisi ve kamera değiştirilmedi.
