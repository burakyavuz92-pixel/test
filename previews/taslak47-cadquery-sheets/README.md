# Taslak4.7 — dış ölçü şeritleri

Altı JPEG ve A5 PDF. Doğrusal ölçüler gerçek görünüş sınırlarının dışında şeritlere yerleştirilir. Küçük açıklıklar iç, toplam ölçüler dış şerittedir. Dar açıklıklar dış oklarla gösterilir. Radyus ve delik çapları kısa kılavuzlarla ayrı etiketlenir; 2× birleştirmesi yapılmaz. Yalnız köşeli parantezli kaynak etiketleri çizilir.

Altı satırda aktif ölçülerin tamamı yerleşmiştir: ilk dört satırda 12, B=0 olan son iki satırda 11 ölçü. Geometri ve STEP dosyaları değişmemiştir. Antet ve toleranslar korunmuştur. Bu inceleme çıktısıdır; üretim onayı değildir. Yeni API çağrısı yapılmamıştır.
