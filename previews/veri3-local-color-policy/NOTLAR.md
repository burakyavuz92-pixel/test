# Yerel yeşil görünürlük politikası

Kullanıcı talebi doğrultusunda kaynak rengi yeşil olan ölçüler için yerel görünürlük kuralı eklendi. Modelden rengin tanınması istenir; yeşilin gizlenmesi kararı normal grup promptundan çıkarıldı. API yanıtındaki görünürlük değiştirilmez, etkin yerel planda yeşil ölçüler hidden yapılır. Nominal geometri, toleranslar, delik varlığı ve siyah ölçülerin gösterimi korunur. Görünmez ölçünün metni, okları ve uzatma çizgileri çizim katmanında atlanır.

75 C# kontrolü geçti. Kayıtlı veri3-first-run yanıtı aynı Excel/JPEG SHA256 bağıyla çevrimdışı review-cad-group komutunda tekrar doğrulandı. Sonuç analysis-only; önceki üç GREEN_FIXED_VISIBLE bloklaması yerine üç COLOR_VISIBILITY_APPLIED uyarısı var. Bu uyarılar kullanıcı girdisini değiştirmeyi istemiyor; yerel kuralın uygulanmasını kaydediyor.

Yeni API çağrısı 0. Yeni çizim 0. Ham model yanıtı elle değiştirilmedi. Native geometri üretimi yapılmadı; dolayısıyla 82 JPEG'in tamamının üretilebildiği henüz bu değişiklikle test edilmedi. Renk beyanı hâlâ modele aittir; yanlış renk algısını bu politika tek başına düzeltmez.
