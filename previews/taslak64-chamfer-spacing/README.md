# Pah yazılarının dışarı taşınması

Pahlar için görünüş dışı yazı boşluğu 16'dan 32 çizim pikseline çıkarıldı (A5 ölçüsünde yaklaşık 3,8 mm). Pah yazıları için görünüşün içine düşebilen yakın konum alternatifleri kapatıldı. Diğer lider türlerinin kuralları korunur.

Kayıtlı Taslak6.4 geometri/referanslarıyla altı JPEG yeniden üretildi; yeni API çağrısı yok. Önceki OCR eksikleri C/E/2,8/25 devam eder. K'nin ölçülendirme dışında kalması kasıtlıdır. Dosyalar tam pafta onayı değildir.
